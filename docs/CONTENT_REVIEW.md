## 写作与证据边界

- 正文编号直接定位本篇来源卡片；来源支持的事实与本站教学案例分别表述。
- 案例、自测、样本卡和流程建议由本站编写；虚构数据明确注明，不冒充模型实测或原论文结果。
- 提示、Schema、检索和自主循环均不自动提供事实正确性、授权或业务成功保证。
- API 文档属于持续更新资料；本文侧重稳定概念，不承诺所有供应商支持同一 Schema 子集。
- 结构化输出提供无需 API 密钥的本地 Zod 示例，测试执行正文中的代码并检查输出，防止示例与实现脱节。

## 内容模型与页面行为

新增可选字段 `learning_objectives`、`exercise`，来源新增 `id`、`publisher`、`kind`、`accessed`、`supports`、`limitation`。旧词条仍兼容；有学习目标的深读词条必须包含自测与完整来源说明，且所有来源必须在正文引用。

正文二级标题生成目录和永久页内锚点；代码块内标题不会进入目录。引用链接直达对应来源卡，卡片列明结论与边界。自测采用原生折叠组件，先显示题目，读者主动展开答案。结构化输出纳入应用开发路径。

内容校验拒绝不存在或重复的来源 ID、缺失的深读元数据、未引用来源，以及晚于词条核验日期的资料核验日期。该校验只保证内容契约，不能代替人工核验事实或检测外部页面是否变化。
